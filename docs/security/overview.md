# Security Docs Overview

Brief overview of Markdown files in this directory. This generated index intentionally excludes `overview.md` itself to avoid a self-referential summary.

| Source | Brief overview |
|---|---|
| [OWASP.md](./OWASP.md) | Reference copy/notes for the OWASP Agentic AI Security Top 10. Covers goal hijacking, tool misuse, identity and privilege abuse, agentic supply-chain vulnerabilities, unexpected code execution, memory/context poisoning, insecure inter-agent communication, cascading failures, human-agent trust exploitation, rogue agents, mappings to OWASP LLM/NHI/AIVSS, an incidents tracker, abbreviations, and acknowledgements. |
| [dehack.md](./dehack.md) | Software-protection and anti-tamper hardening plan for `tanit` / `tanit-cli.exe`. Prioritizes real controls such as DLL search hardening, signed binary manifests, resource and CLI policy, SecurityGateway enforcement, UIAutomation gating, sandboxed sidecars, tamper-evident audit logging, build mitigations, module/memory telemetry, and optional anti-debug signals. |
| [p2p.md](./p2p.md) | Compact design for a C++ secure P2P chat and file-exchange system. Proposes WebRTC DataChannels, WebSocket signaling, STUN/TURN fallback, Ed25519/OpenPGP identity keys, Noise/Double Ratchet sessions, XChaCha20-Poly1305 file chunks, BLAKE3 manifests, and server-blind end-to-end encryption rules. |
| [research.md](./research.md) | Short research link dump and notes on AI coding-assistant hardening. Points to sources on Claude/Cursor/Copilot vulnerabilities, supply-chain incidents, OpenSSF guidance, and a seven-layer defense model covering assessment, pre-execution gates, supply chain, malware scanning, credential hygiene, MCP audits, and governance. |
| [sandbox.md](./sandbox.md) | Design and experiment log for Windows AppContainer/LPAC sandboxing of MCP tool workers. Describes broker/worker architecture, AppContainer + Job Object + process mitigation layers, shared-folder ACL grants, privilege-escalation request flow, IPC protocol, worker rules, sandbox tiers, validated experiments, and next implementation steps. |
| [security.md](./security.md) | Implementation reference for the Security Gateway. | [ss-todos.md](./ss-todos.md) | Secure storage roadmap and status tracker. Documents the threat model for untrusted rendered documents reaching native command execution, plus defenses including markdown sanitization, GPO run gates, origin pinning, production DevTools gating, nonce-based CSP, local Monaco bundling, ADMX policy generation, verification steps, and deferred Mark-of-the-Web provenance gates. |
